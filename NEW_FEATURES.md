# Новые функции: Овервью по всем сессиям и месячные отчеты

## Обзор

Добавлена функциональность для:
- Общей статистики по всем сессиям за все время
- Месячной статистики с автоматической фиксацией
- Архива месячных отчетов
- Расчета достижений и рекордов
- Визуализации активности (текстовые графики)

## Новые команды бота

### `/allstats` - Общая статистика за все время

Показывает:
- Общий рейтинг игроков за все время
- Количество матчей и игроков
- Интерактивные кнопки для:
  - Просмотра достижений
  - Графика активности
  - Перехода к месячной статистике

**Пример использования:**
```
/allstats
```

### `/monthstats [год] [месяц]` - Статистика за месяц

Показывает:
- Рейтинг игроков за выбранный месяц (или текущий)
- Количество матчей и игроков за месяц
- Кнопки для навигации между месяцами
- Достижения месяца
- График активности по дням

**Примеры использования:**
```
/monthstats              # Статистика за текущий месяц
/monthstats 2025 11      # Статистика за ноябрь 2025
```

### `/reports` - Архив месячных отчетов

Показывает:
- Список всех сохраненных месячных отчетов
- Дату создания каждого отчета
- Интерактивные кнопки для просмотра конкретного отчета

**Пример использования:**
```
/reports
```

## Достижения и рекорды

Система автоматически отслеживает:

1. **MVP месяца/периода** - Игрок с лучшим процентом побед (минимум 3 игры)
2. **Самый активный игрок** - Наибольшее количество сыгранных матчей
3. **Лучшая серия побед** - Максимальное количество побед подряд
4. **Безупречный игрок** - Игрок без поражений (минимум 3 игры)
5. **Самый результативный матч** - Матч с наибольшей суммой очков
6. **Самая крупная победа** - Победа с максимальной разницей в счете
7. **Самый близкий матч** - Матч с минимальной разницей в счете

## Визуализация

### График активности

Текстовый график показывает количество матчей по неделям/дням:

```
📊 График активности по неделям:

2025 нед. 44: ████████████████████ 8
2025 нед. 45: ████████ 3
```

### Рейтинговая таблица

Показывает:
- Место в рейтинге (🥇🥈🥉 для топ-3)
- Текущая серия (🔥 для побед, ❄️ для поражений)
- Соотношение побед/поражений
- Процент побед
- Количество очков и матчей
- Лучшая серия побед

```
🥇 Nikita ❄️1
   📊 5-3 (62.5% побед)
   🎾 очков: 12:10 | Матчей: 8
   ⭐ Лучшая серия: 2
```

## Автоматическая фиксация месячных отчетов

### Как работает

- Бот автоматически проверяет наличие новых месяцев каждый час
- 1-го числа каждого месяца создается отчет за предыдущий месяц
- Отчет сохраняется в базу данных
- В чат отправляется уведомление о создании отчета

### Формат уведомления

```
📊 ИТОГИ НОЯБРЯ 2025

Автоматически создан месячный отчет!

🎾 Матчей: 15
👥 Игроков: 5

Используйте /monthstats 2025 11 для просмотра
```

### Хранение отчетов

- Отчеты хранятся в таблице `monthly_reports`
- Каждый отчет содержит полную статистику на момент создания
- Отчеты не изменяются при добавлении новых игр
- Можно пересоздать отчет вручную (функция для админа)

## Технические детали

### Новые таблицы БД

**monthly_reports:**
- `id` - Уникальный идентификатор
- `chat_id` - ID чата
- `year` - Год отчета
- `month` - Месяц отчета
- `stats_json` - JSON с полной статистикой
- `created_at` - Дата создания отчета

### Новые методы в database.js

- `getSessionsByPeriod(chatId, startDate, endDate)` - Получение сессий за период
- `getGamesByPeriod(chatId, startDate, endDate)` - Получение игр за период
- `getAllChatGames(chatId)` - Все игры чата
- `getAllChatPlayers(chatId)` - Все игроки чата
- `saveMonthlyReport(chatId, year, month, statsJson)` - Сохранение отчета
- `getMonthlyReport(chatId, year, month)` - Получение отчета
- `getMonthlyReports(chatId, limit)` - Список отчетов
- `hasMonthlyReport(chatId, year, month)` - Проверка существования отчета

### Новый модуль stats-utils.js

Функции для расчета статистики:
- `calculatePlayerStats(games, players)` - Расчет статистики игроков
- `calculateAchievements(playerStats, games)` - Расчет достижений
- `generateActivityChart(games, periodStart, periodEnd)` - График активности
- `generateMonthlyActivityChart(games, year, month)` - Месячный график
- `formatPlayerRanking(playerStats, options)` - Форматирование рейтинга
- `formatAchievements(achievements, games)` - Форматирование достижений
- `generateMonthlyStatsData(games, players, year, month)` - Генерация данных для отчета

## Интерактивность

Все новые команды поддерживают интерактивные кнопки:

- **Навигация между месяцами** - Переключение вперед/назад
- **Просмотр достижений** - Детальная информация о рекордах
- **График активности** - Визуализация по периодам
- **Переход к отчетам** - Быстрый доступ к архиву

## Производительность

- Месячные отчеты кэшируются в БД
- Индексы на датах для быстрых запросов
- Агрегация данных происходит только при первом запросе
- Сохраненные отчеты загружаются мгновенно

## Совместимость

- Полностью совместимо с существующей функциональностью
- Не требует миграции данных
- Автоматическое создание новых таблиц при первом запуске
- Работает с существующими сессиями и играми
