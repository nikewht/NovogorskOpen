# Telegram Бот для учета статистики игр в теннис

Бот для Telegram, который позволяет вести статистику игр в теннис в групповых чатах с друзьями.

## Возможности

- Создание игровых сессий для тренировок с выбором режима игры
- Поддержка 4 режимов игры:
  - ⚡ Короткий матч (до 2 побед в геймах)
  - 🎾 Классический сет (до 6 геймов)
  - 🏆 Матч из 2 сетов
  - 👑 Матч из 3 сетов
- Присоединение игроков к сессии
- Интерактивная запись результатов матчей через кнопки (без ручного ввода)
- Просмотр статистики текущей сессии
- Двухуровневая навигация по истории сессий с детальной статистикой
- Рейтинг игроков с медалями для топ-3 мест
- Автоматический подсчет побед, поражений, счета по геймам/сетам и процента побед для каждого игрока

## Установка и настройка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите бота [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например, "Tennis Stats Bot")
4. Введите username для бота (должен заканчиваться на "bot", например, "my_tennis_stats_bot")
5. Скопируйте токен, который вам даст BotFather (выглядит примерно так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Настройка проекта

1. Клонируйте или скачайте проект
2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта и добавьте туда токен бота:
```bash
cp .env .env
```

4. Откройте файл `.env` и вставьте ваш токен:
```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

### 3. Запуск бота

```bash
npm start
```

Для разработки с автоматической перезагрузкой:
```bash
npm run dev
```

## Использование

### Добавление бота в группу

1. Добавьте бота в ваш групповой чат с друзьями
2. Отправьте команду `/start` для получения списка команд

### Основные команды

#### Управление сессиями

- `/newsession` - Создать новую игровую сессию (с интерактивными кнопками)
- `/join` - Присоединиться к текущей сессии
- `/leave` - Покинуть текущую сессию
- `/endsession` - Завершить текущую сессию и показать итоговую статистику

**Как присоединиться к сессии:**
1. После создания сессии появятся кнопки "👥 Присоединиться" и "❌ Покинуть сессию"
2. Нажмите "Присоединиться" или используйте команду `/join`
3. Ваше имя добавится в список участников
4. Если присоединились случайно - нажмите "Покинуть сессию" или используйте `/leave`
5. Список участников обновляется автоматически

#### Запись результатов

- `/addgame` - Добавить результат матча (интерактивно)

**Как это работает:**
1. Введите команду `/addgame`
2. Выберите первого игрока из списка кнопок
3. Выберите второго игрока из списка кнопок
4. Выберите счет игры (2:0, 2:1, 0:2, 1:2)
5. Результат будет автоматически сохранен!

#### Просмотр статистики

- `/stats` - Показать статистику текущей сессии
- `/history` - Показать историю предыдущих сессий (интерактивно)

**Команда /history:**
1. Введите команду `/history`
2. Увидите список всех сессий с краткой информацией (дата, количество игроков, количество матчей)
3. Нажмите кнопку "📊 Подробнее" для просмотра детальной статистики любой сессии
4. В детальной статистике отображается:
   - Рейтинг игроков с медалями (🥇🥈🥉) для топ-3
   - Победы/поражения каждого игрока
   - Счет по геймам
   - Процент побед
   - Список всех матчей сессии

#### Справка

- `/help` - Показать справку по командам

## Пример использования

1. **Создание сессии:**
   ```
   /newsession
   ```
   Бот предложит выбрать режим игры:
   ```
   🎾 Выберите режим игры:

   ⚡ Короткий матч (до 2 побед в геймах)
   🎾 Классический сет (до 6 геймов)
   🏆 Матч из 2 сетов
   👑 Матч из 3 сетов
   ```

   После выбора режима, бот отправляет сообщение с кнопками:
   ```
   ✅ Новая сессия создана! ID: 1
   🎮 Режим: ⚡ Короткий матч (до 2 побед в геймах)

   👥 Участники:
   Пока никто не присоединился

   [👥 Присоединиться] [❌ Покинуть сессию]
   [🎾 Добавить результат игры]
   ```

2. **Присоединение игроков:**
   - Игроки нажимают кнопку "Присоединиться" или используют `/join`
   - Сообщение автоматически обновляется со списком участников

3. **Запись результатов матчей:**
   - Нажмите кнопку "🎾 Добавить результат игры" или введите `/addgame`
   - Выберите первого игрока из кнопок
   - Выберите второго игрока из кнопок
   - Выберите счет (варианты зависят от выбранного режима):
     - **Короткий матч**: 2:0, 2:1, 0:2, 1:2
     - **Классический сет**: 6:0, 6:1, 6:2, 6:3, 6:4, 7:5, 7:6 и обратные
     - **Матч из 2 сетов**: 2:0, 2:1, 0:2, 1:2
     - **Матч из 3 сетов**: 2:0, 2:1, 0:2, 1:2
   - Повторите для каждого матча

4. **Просмотр статистики:**
   ```
   /stats
   ```
   Бот покажет:
   - Список всех сыгранных матчей
   - Статистику по каждому игроку (побед/поражений, геймы, процент побед)

5. **Завершение сессии:**
   ```
   /endsession
   ```
   Бот покажет итоговую статистику и закроет сессию.

## Структура данных

Бот использует SQLite базу данных для хранения:
- **Сессии**: информация о каждой игровой сессии
- **Игроки**: участники каждой сессии
- **Игры**: результаты всех матчей

База данных автоматически создается при первом запуске бота в файле `tennis_stats.db`.

## Технические детали

- **Node.js** - платформа для запуска

## Режимы игры

Бот поддерживает 4 режима игры:

### ⚡ Короткий матч (до 2 побед в геймах)
Быстрый формат для тренировок. Игра до 2 выигранных геймов (например: 2:0, 2:1).

### 🎾 Классический сет (до 6 геймов)
Стандартный теннисный сет. Игра до 6 геймов с перевесом в 2 гейма, или тай-брейк при счете 6:6.
Возможные счета: 6:0, 6:1, 6:2, 6:3, 6:4, 7:5, 7:6.

### 🏆 Матч из 2 сетов
Матч, состоящий из двух сетов. Записывается только финальный счет по сетам (2:0, 2:1).

### 👑 Матч из 3 сетов
Матч до 2 выигранных сетов из 3 возможных. Записывается только финальный счет (2:0, 2:1).
